# Android device tree for KLIPAD KL605 (KL605)

The KLIPAD KL605 is a low-range smartphone from Kliver France Import announced in 2022 and manufactured by Fise Group.

## Device specifications

| Device                  | KL605                                                 |
| ----------------------: | :---------------------------------------------------- |
| SoC                     | Mediatek MT6739V                                      |
| CPU                     | 4x1.5 GHz ARM Cortex-A53                              |
| GPU                     | Adreno 619                                            |
| Memory                  | 2 GB                                                  |
| Shipped Android version | Android 12 Go Edition                                 |
| Storage                 | 16GB                                                  |
| Battery                 | Li-ion 3000 mAh, removable                            |
| Dimensions              | 154 x 76 x 12 mm                                      |
| Display                 | 480 x 960 pixels, 5.9 inches                          |
| Rear camera 1           | 8 MP, ov8865                                          |
| Front camera            | 2 MP, ov2680                                          |
